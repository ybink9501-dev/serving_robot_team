## 파일 간 데이터 경로

주문·완료 신호: `tools/send_signal.py` 또는 UI → `/fleet/request` → `fleet.py` → `/<robot>/serving/request` → `mission.py` → `/<robot>/navigate_to_pose`.

정상 서빙: `GOING_PICKUP` → `WAIT_LOAD` → `GOING_TABLE` → `WAIT_HANDOVER` → `RETURNING_HOME` → `COMPLETED`. 단순 직접 서빙: `GOING_DIRECT` → `WAIT_HANDOVER` → `RETURNING_HOME` → `COMPLETED`. Nav2 미세접근 실패나 시간 초과는 `ERROR`로 기록.

속도 경로: Nav2 `cmd_vel_nav` → Velocity Smoother `cmd_vel_nav_smooth` → Semantic Safety `cmd_vel_semantic` → Collision Monitor `cmd_vel` → `ros_gz_bridge` → Gazebo DiffDrive. 미세 접근은 별도 `cmd_vel_fine`을 Safety가 선택해서 동일 Collision Monitor를 통과.

센서 경로: Gazebo `/robot_N/scan_raw` → 브리지 → `scan_reframe` → `/robot_N/scan` → AMCL/Nav2 Costmap/Collision Monitor/Safety. Gazebo `/model/robot_N/odometry` → `/robot_N/odom` → odom TF 및 Fleet·Nav2.

주문·사람 입력은 동일한 파일의 경로를 하드코딩하지 않는다. Robot 01과 Robot 02는 로봇별 namespace로 격리하고 `map` 좌표계를 공유한다.
