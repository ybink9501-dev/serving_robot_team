## 실제 수용 시험 순서

1. `bash tools/preflight.sh` 및 `colcon build --symlink-install`; 빌드 성공 필요.
2. 01 Gazebo 월드만 실행하여 로봇 미생성 확인. 02 실행 후 로봇 2대 생성·Gazebo 서버 1개 확인.
3. `/clock`, `/robot_01/scan`, `/robot_02/scan`, TF, AMCL 상태와 Nav2 Lifecycle 활성 확인.
4. **첫 구동은 Robot 01 Table 01부터** `python3 tools/trial.py robot_01 table_01`; 화면상 실제 이동 및 단계별 미션 상태 비교.
5. T02~T04와 HOME에 동일 제어 적용, Robot 02 Table 02 주행 확인. 각 도착 좌표를 Gazebo Truth로 측정.
6. 실주행에서 감속/정지/회피, 센서 단절, 사람 시나리오, Fleet 중복 주문·두 로봇 교행·충돌 위험 실험.
7. 30~60분 연속 운용 및 장애 복구까지 확인한 경우에만 **실제 시스템 통합 완료**로 판정.

## 실험 중단 기준

- ROS 핵심 노드나 LiDAR가 미발행, TF 부재, `traffic_hold=true`, Semantic Safety 데이터 stale, Collision Monitor 비활성화
- 속도 명령이 Collision Monitor를 우회함
- 부엌 적재 전 `LOAD`를 받은 채 임의로 계속 이동함
- 서빙 완료 전 자동 HOME 복귀 또는 목표 오차 미검증인데 `COMPLETED` 표시됨

**정적 검사 통과를 실제 주행 완료로 표현하지 않는다.**
