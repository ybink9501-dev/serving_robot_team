# 지도 적응·선도착·선주문 우선권

기준일: 2026-10-31. 개인 cafe_autonomy·개인 사람/시험 설정 범위.

## 적용 규칙
1. 현재 지도에서 해당 통로의 입구 도착 구간에 먼저 들어온 로봇이 우선 통과한다.
2. 같은 Fleet 관측 주기에 도착하면 유효한 임무/주문 신호를 먼저 수신한 로봇이 우선한다.
3. 한 번 정한 우선권은 양보 경로가 짧다는 이유로 뒤집지 않는다. 후순위 로봇의 안전한 대피 경로를 못 찾으면 양쪽을 안전하게 대기시키고 다시 검증한다.
4. 이미 통로를 점유한 로봇이 있는 경우에는 충돌 방지를 위해 그 점유 상태를 먼저 보호한다.
5. 실제 주행은 계속 Nav2·Semantic Safety·Collision Monitor를 통과한다. 우선권 자체가 이동/충돌 회피의 허가는 아니다.

도착 구간은 통로 영역의 입구 경계와 기존 zone_approach_margin 0.45m + 로봇 반경 0.33m를 기준으로 한다.
현재 Fleet 관측 주기는 0.25초다. ‘동시’는 이 관측 해상도에서 같은 주기에 처음 도착한 경우이며, 물리적으로 완전히 같은 마이크로초를 판별한다는 뜻은 아니다.
초기에는 양쪽 위치·센서 상태를 확보한 뒤 도착 기록을 시작한다. 주문이 없어도 입구에 먼저 와 있는 실제 위치를 기록하고, 통로 진입 임무가 생겼을 때 순위에 사용한다.
입구를 떠나면 해당 도착 기록을 지운다. 센서가 누락됐다는 이유만으로 로봇이 떠났다고 추정하지 않는다.

## 주문 신호 순서
HTTP·ROS 입력을 하나의 FIFO 수신 대기열로 통합한다.
유효한 새 request_id를 수락할 때 received_seq/received_at을 Task에 저장하고 SQLite의 요청 JSON에 보존한다.
동일 request_id 재요청은 기존 번호를 재사용한다. 중복/재시도로 통행 우선권을 앞당길 수 없다.
기존 DB에 번호가 없는 과거 요청은 원래 요청 행의 삽입 순서를 이관한다. 재시작 뒤에도 수신 순서를 이어간다.

## 지도 변경·전방 관측
- 지도에 등록된 통로/통행 영역이 있으면 이를 사용하며, 통로 이름·좌표는 코드에 고정하지 않는다.
- 저장 점유 지도와 실제 Nav2 경로에서 양쪽의 알려진 벽이 확인되는 좁은 구간을 찾아 미등록 통로도 추가한다.
  폭은 기존 로봇 반경/간격을 기준으로 평가한다. 미확인 셀을 벽이나 자유 공간으로 간주하지 않는다.
- 지도 원점·해상도·회전을 변환에 반영한다. 새 지도 식별값이 달라지면 이전 도착 기록·경로·자동 통로·진행 중 허가를 무효화한다.
  운행 중 지도를 갑자기 교체한 경우에는 이전 좌표로 계속 움직이지 않고 정지한다. 해당 장소 프로필과 초기 위치추정을 맞춰 다시 시작한다.
- 전방 카메라/LiDAR 상태가 신선하고, 입구가 전방 관측 범위 및 알려진 자유 시야 안에 확인될 때 진입 전 우선권을 확정한다.
- 상대가 입구를 막아 Nav2 경로가 아직 없으면 목적지의 통로 진입 의도로 ‘순서 결정’만 먼저 한다.
  유효한 현재 Nav2 우회 경로가 이미 있으면 그 경로를 우선해 불필요한 통로 예약을 줄인다.
  양보 이동은 반드시 계산·검증된 Nav2 경로를 사용하며, 목표 의도를 cmd_vel이나 미검증 경로 실행에 사용하지 않는다.

자동 추출은 알려진 지도에서 확인되는 좁은 경로 구간에 대한 기능이다. 지도 생성·AMCL 초기화·테이블 의미 위치 등록을 대신하지 않는다.
가림/미확인 지형이나 안전한 양보 경로 부재에는 기존 안전 정지/재검증이 유지된다.

이 사례는 Robot 01의 신호 수신 번호가 1, Robot 02가 2였지만 먼저 입구에 도착한 Robot 02를 선택했고 실제로 먼저 통과했다.
동시 도착 사례는 두 로봇 모두 batch=1이었으며 수신 번호가 더 빠른 Robot 02를 선택했다.

## 회귀·추가 보완
- 개인 전체 회귀 190개 통과(37.79초), cafe_autonomy·serving_robot_person_simulator 빌드 성공.
- 원점 이동·90도 회전된 지도에서 통로 추출, 이전 지도 이력 초기화, 등록 통로 중복 방지, 미확인 영역 거절 검증.
- 중복 주문·재시작의 수신 번호 보존, HTTP/ROS 공통 FIFO, 우선 로봇에 대피를 강요하지 않는 조건 검증.
- 동시 도착 초기 시험에서 Robot 02의 센서 미갱신 상태가 관측됐다. 별도 구독에서는 데이터가 정상 도착했고,
  후속 계측에서 스캔이 /clock보다 앞서는 순서도 확인됐다. 미래 시각 스캔은 시계가 따라온 뒤 다시 검증하도록 보완했다.
  유효한 ROS 시각 및 기존 수신 시각 기준 0.5초 제한을 모두 통과해야 하며, 재검사로 신선도를 연장하지 않는다.
- 자동 통로 초기 시험은 양쪽 완성 경로를 기다리다 상대 입구 점유로 한쪽 계획이 실패했다.
  앞의 진입 의도 기반 예약과 검증된 비활성 Goal의 RECOVERY_WAIT 양보 인계로 수정 후 통과했다.
