# 불확실 이력 관련 개인 코드 수정 — 2026-10-30

## 범위와 판정
수정은 개인 cafe_autonomy의 dynamic_policy.py, dynamic_obstacles.py와 개인 회귀 테스트에 한정한다.
과거 불확실 트랙 76개는 실행별 ID 집계이며, 물체 76개나 버그 76개를 뜻하지 않는다.
관측 유실 후 빈 공간을 확인하지 못해 유지하는 불확실 상태는 필요한 안전 동작이다.
실제 장애물은 불확실 이력만으로 삭제하지 않는다. 안전 거리·속도·정지 한계는 변경하지 않았다.

## 남은 검증
과거 76개 트랙을 실제 물체와 모두 일대일 대응하여 해소했다는 뜻은 아니다.
가려짐·유실 때문에 현재 증거가 부족한 트랙은 계속 불확실로 남아야 한다.
좁은 복도 마주침, 사람 근접 감속·정지·우회·재출발 및 다른 실제 SLAM 지도에서의 종단 시험은 별도다.
합성 지도에서 빠진 의자가 장애물로 남아 주행을 막는 문제도 이번 불확실 버그 수정과 구분한다.
