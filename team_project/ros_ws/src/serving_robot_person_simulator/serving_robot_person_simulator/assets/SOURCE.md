# Standing person mesh

`standing.dae` is copied from Gazebo Fuel, OpenRobotics model `Standing person`, version 3 (`meshes/standing.dae`). The COLLADA file credits Marina Kollmitz as author. It is used as the person simulator visual mesh; the simulator retains its original collision shape. Source: https://app.gazebosim.org/OpenRobotics/fuel/models/Standing%20person
